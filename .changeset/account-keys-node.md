An `environmentId` option on the client sends `X-Canopy-Environment`, so an account API key can reach the routes that act in an Environment; `RequestOptions.environmentId` names another Environment for one call, or `null` none. The generated types cover the management API: Applications and Environments with their settings, single sign-on, the auth domain and SCIM, administrator roles, grants and administrators, billing reads, the Account and account webhooks (298 operations, up from 201). The skill's choosing, node and mistakes references say which key goes where and how to provision an Environment with an account key.
